v3: logic without code

Claude's proposal, for the owner to try (2026-11-22), in the redesign's look. Every part here is new in v3; the rest of the editor is as built. The trigger cards work: each trigger has four sections, When, If, Do and Repeat, each a list of one-sentence rows. Click an underlined word to change it (yellow ones aren't set yet), "Add check" or "Add action" to add a row, × on a row to remove it, the switch to turn a trigger off, and … to rename, duplicate or delete it. The tags field works too. Dragging, undo and the level view don't. The names shown (coins, player) are only an example level.
