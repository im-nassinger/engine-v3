Collision grid

How a creator decides what hits what. Every entity can carry tags, such as player or enemy. The World's PhysicsWorldComponent card has an Edit collision grid button, which opens this window. Tick a box and those two tags collide; untick it and they pass through each other. Try it: click the boxes, hover them, add or remove a tag.

Collision grid

Tags not in the grid don't change collisions. A new tag collides with everything until you untick boxes. The grid applies to sensors too: an unticked pair never fires.

The rules behind it

  • An entity with no tag in the grid counts as Default.
  • An entity with two grid tags hits something if either tag does.
  • Changing an entity's tags during play changes its collisions at once.
  • Up to 64 tags fit in the grid, Box2D's limit.
  • Ragdolls don't need tags. The parts of a ragdoll are held together by hinges, and a hinge stops the two parts it joins from hitting each other. Two ragdolls still hit each other.
  • Right-click two entities and pick Why do these collide? to see which rule decides.
