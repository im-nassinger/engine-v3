# Stage 18 in steps: Before v2

## TL;DR

Written under the standing yes (2026-11-17). Stage 18 builds every change in [before-v2.md](../before-v2.md), the owner's changes asked for after v1's stages and before v2, and nothing of v2. Each step builds one change, or one half of a bigger one, and updates the requirement and architecture docs that change lists as "To update when planned", in the same commit. Each step ends with its tests, `npm run check` and a commit, and marks its change built in [before-v2.md](../before-v2.md) once all of it is. The open questions of changes 1 and 3 are decided in step 1 and written in [before-v2.md](../before-v2.md).

The small changes come first, so each is built and tested on today's code before the resizing changes move the Select tool under them. Change 1 comes before 3, 2 and 8, because those three build on how a resize works after it.
