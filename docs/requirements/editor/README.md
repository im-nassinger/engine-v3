# Editor

## TL;DR

Everything about the editor that isn't specific to one kind of entity: the workspace, the tools, the Entity inspector, selection, groups, the Entities viewer and undo. **In v1** you get fixed panels over a full-window level view, three of the seven tools (Select, Shape, Joint), pan and zoom, a grid, the Entity inspector with cards and partner notes, copy and paste, undo, click and box selection, handles, grouping, the Entities viewer and the eye icon. **In v2** come the other four tools and the searchable shortcut list. **In v3** come panel resizing, snapping to entities, copying values, tips and more warnings, multi-entity resize and rotate, the path bar, hover outlines, Entities viewer search and the lock icon.
