# Plan for v1

## TL;DR

v1 in **18 small stages**, each tested on its own before the next starts. The order goes from the inside out: the model and its data format first, then geometry, then drawing a level, then editing it (history, panels, tools, clipboard), then saving, then physics and the determinism test, then test play. **Every stage names the requirement files it implements** and when it is done. The small features the owner put in v1 (owner, 2026-11-14) are built in their stage. How each part is built is in [architecture/](architecture/README.md).

## How a stage works

- A stage starts by reading its docs and ends with its tests passing, ESLint and the type checks clean, its speed numbers (if any) written down, `docs/progress.md` updated, and a commit.
- A stage never builds something a later stage owns. If it needs a piece early, it builds the smallest version and says so in progress.
- Anything the requirements don't answer becomes an open question, not a silent decision.
